# Inventory (ECIS.pdf phase 13, core built)

Moved from CLAUDE.md unchanged (one sentence per line). Keep this note current when the feature changes.

**Inventory (ECIS.pdf phase 13, core built)**: the old `inv_*` tables are empty, so it is new `ecis_*` tables (`V031_inventory.sql`, applied): products (moving average cost, batch and expiry tracking, reorder level), warehouses, categories, units, batches, an **insert-only ledger** (`ecis_inventory_txn`) and a balance changed only with a ledger row by `StockService.post` (never touch `ecis_inventory_balance` elsewhere; the goods receipt and the point of sale must post through it); RECEIVE/ISSUE/RETURN/TRANSFER by a STOREKEEPER, ADJUSTMENT/DAMAGE/EXPIRY and stock counts approved by a different STOCK_APPROVER, stock never below zero, expired batches cannot go out, SALE reserved for POS; no general ledger entries yet; screen = Inventory tile (`InventoryPage`); `InventoryRulesTest`, `InventoryFlowTest`; see `documentation/inventory-design.md`. **Goods receipts feed stock** (`V032_receipt_stock.sql` applied: an order line may name a product, the receipt names the warehouse and, for batch products, the batch and expiry; a RECEIVE is posted through `StockService` at the order price; reversing the receipt takes the stock back out and is refused if it has been used; `GoodsReceiptStockTest`).
Not built: bins, stock accounting, sales.
