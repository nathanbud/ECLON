# Database connection (choose where the server connects)

- **One active database per backend.** `SwitchableDataSource` (`ph.coop.core.connection`) is the application's only DataSource. `ConnectionController` switches it: it probes the target first (must have the `access` table), audits `connection.switch` in the old and the new database, swaps the pool (old pool retired after 15 s), then calls every `OnConnectionSwitch` bean so caches forget the old database (`Db`, `DrawerBalances`, `LoanReports`, `InboxController`, `AuditLog.forgetShape`). **A new class that caches facts about the database must implement `OnConnectionSwitch`.**
- **Saved connections** live in `coop.connections.file` (default `./data/connections.json`, git-ignored; not in the database, because sign-in needs it). Fields: name, host, port, dbName, branch, default flag. No password: every connection uses `DB_USER`/`DB_PASSWORD`. With none saved, the server's own `spring.datasource.url` shows as the read-only "Server startup setting". The default connection is opened at start (falls back to the startup setting, with a warning, if unreachable).
- **Who:** `GET /api/public/connections` (names, database, branch; no host or port) is public; everything under `/api/admin/connections` (list, create, update, delete, `databases`, `branches`, `test`, `{id}/activate`) needs `ROLE_SUPERADMIN`. Switching is not possible before sign-in, because people are read from the database. Hosts, ports and database names are validated (`ConnectionRules`); saving checks the database answers and reads the branch name from `branches`.
- **Desktop app:** the sign-in screen's Connection window (`ConnectionDialog`) keeps a list of servers in browser storage (`api/server.ts`; `apiUrl()` prefixes every `/api` call, so the installed app can reach a server at another address; CORS origins in `coop.cors.allowed-origins`). Settings > System > Database connection is `DatabaseConnectionsPage`. The branch is stored and shown but no screen uses it as a filter yet.
- Tests: `ConnectionRulesTest`, `ConnectionStoreTest`, `SwitchableDataSourceTest`, `ConnectionControllerTest` (the live switch test is skipped when the server has no second cooperative database), `server.test.ts`, `ConnectionDialog.test.tsx`, `DatabaseConnectionsPage.test.tsx`.
