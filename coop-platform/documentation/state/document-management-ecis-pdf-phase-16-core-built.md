# Document management (ECIS.pdf phase 16, core built)

Moved from CLAUDE.md unchanged (one sentence per line). Keep this note current when the feature changes.

**Document management (ECIS.pdf phase 16, core built)**: `ecis_document` + `ecis_document_grant` (`V035_documents.sql`, applied; `DOC-yyyy-nnnnnn`), files behind `DocumentStore` (`LocalDocumentStore`, folder `coop.documents.root`, default `./data/documents`, git-ignored, never overwrites; a MinIO/S3 store replaces it later); uploads limited to PDF, PNG, JPEG, docx, xlsx, CSV, txt up to 10 MB with the first bytes checked against the extension and the file name cleaned; **access is by classification** (PUBLIC, INTERNAL, CONFIDENTIAL, RESTRICTED) plus per-document grants, a document one may not read is not listed and looks nonexistent, every download is audited and compared with its SHA-256 (a mismatch is not released); new versions supersede, removal only after the retention date (default 10 years for member, loan, journal and asset documents, 5 for the rest) and the file stays; `/api/documents`; role DOCUMENT_CLERK (granted by API); Documents tab on the member profile, Documents section in the asset window, Settings > Documents; `DocumentRulesTest`, `DocumentFlowTest`; see `documentation/document-management-design.md`.
Not built: MinIO/S3, encryption at rest, virus scanning, physical destruction and legal holds (privacy phase 19).
